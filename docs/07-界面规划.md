# 界面规划（v0.2 桌面）

> 目标一句话：**让它看起来、用起来像 Windows，但它骨子里是 AI 原生系统。**
>
> 用户原话：「你就模仿 Windows 知道不」。
> 所以布局、交互习惯对齐 Windows；但每一处界面能力都必须有等价的
> MCP 工具（人点得到，智能体也调得到）。

## 1. 原则

| 原则 | 含义 | 反例 |
| --- | --- | --- |
| 像 Windows | 任务栏在底部、开始按钮在左、时钟在右、窗口按钮在右上、双击图标打开 | 平铺铺满（IDE 感）、没有任务栏 |
| AI 原生 | 状态栏/开始菜单/托盘能看见智能体数量与资源；所有界面动作有 MCP 等价物 | 只给"人"做的按钮，智能体做不到 |
| 一致性 | 颜色/字体/圆角/间距只从 `docs/06-视觉规范.md` 取值 | 每个组件自己拍配色 |
| 软渲染友好 | 无 GPU：不用模糊、不用大阴影；动画 ≤120ms 的淡入/位移 | 60fps 的亚克力毛玻璃 |
| 幂等启动 | 同一应用只起一个实例，重复执行启动脚本不叠窗口 | 上次那种 4 个终端叠一起 |

## 2. 屏幕分区

```
┌──────────────────────────────────────────────────────────────┐
│  桌面区（壁纸 + 桌面图标 + 应用窗口）                          │
│                                                              │
│  ▣ 此电脑          ┌─ 窗口标题栏 ────────────── ▭ □ ✕ ┐      │
│  ▣ 工作区          │                                    │      │
│  ▣ 软件商店        │            应用内容                │      │
│  ▣ 终端            │                                    │      │
│                    └────────────────────────────────────┘      │
├──────────────────────────────────────────────────────────────┤
│ [⊙] │ [终][文][店] [窗口列表…]              [状态] 12:34     │ 40px
│                                                    10-19      │
└──────────────────────────────────────────────────────────────┘
```

* **没有顶栏**（Windows 没有；工作区信息并进任务栏）
* 任务栏高 **40px**，占满宽，`#12151A`，上沿 1px `#292E36`
* 桌面图标**左列竖排**，图标 56px，间距 12px

### 2.1 开机状态（2026-10-20 起）

开机**只启动任务栏**，不预开任何应用——和 Windows 一致：桌面只有壁纸和任务栏，
程序从任务栏/开始菜单里点开。想恢复"开机带终端+商店"设
`SHUIOS_AUTOSTART=full`（在 `shuios-desktop.env` 或 unit 环境里）。

### 2.2 窗口装饰（谁会画标题栏与关闭按钮）

| 应用 | 装饰来源 | 有没有 ✕ |
| --- | --- | --- |
| sway 自身 | **不画**（wlroots 只画像素边框） | 无 |
| `shui-store`、`shui-files`、`shui-settings` | GTK3 客户区装饰（CSD headerbar） | 有（▭ □ ✕ 在右上） |
| `shui-panel`（任务栏 / 开始菜单） | 自绘，无标题栏 | 无（任务栏常驻；菜单点别处或选项后收起） |
| `foot` 终端 | **foot 自己的 CSD**（`foot.ini` 的 `[csd] preferred=client`） | 有 |
| 没有 CSD 的老程序 | 只能靠 `Super+Q` / 任务栏右键 | 无 |

要点：sway 永远不画标题栏，所以"窗口能不能关"取决于**客户端自己画不画**。
新加的 GTK 应用默认就有；非 GTK 程序必须显式打开 CSD。

## 5. 技术架构

### 5.1 现状（V24/V25/V27 已达成）

```
sway (wlroots)
  ├ swaybg 壁纸（layer background）
  ├ shui-panel = 真 layer-shell 任务栏（layer TOP，exclusive_zone 40）
  │    └ 点击开始 → 独立 toplevel shui-panel --menu（460×520）
  ├ shui-idle = 空闲计时（evdev）+ 锁屏看门狗（500 ms 检查 lock.pid）
  ├ shui-lock = 锁屏（layer OVERLAY，键盘 EXCLUSIVE）+ sway mode "shui-lock"
  ├ shui-settings = 设置中心（网络 / 声音 / AI / 关于）
  └ 应用窗口由任务栏按钮管理：启动 / 聚焦 / 最小化（scratchpad）/ 右键关闭
```

不再需要 swaybar/waybar 占位，也没有浮动 Dock 的硬坐标。

### 5.2 关键改造（V24 已完成）

1. **layer-shell 绑定**：`gtk-layer-shell` 0.9.0 + 生成的协议代码；任务栏
   `layer=TOP`、锚定底/左/右、`exclusive_zone=40`，应用窗口自动避开。
2. **开发闭环**：UI 二进制交叉编译后 `scp` 到 `/var/lib/shuios/dev/` 直接跑，
   迭代从 8 分钟 → 20 秒。
3. **开始菜单独立进程**：layer surface 不能弹 xdg_popup，菜单必须是独立
   toplevel（app_id `shui-panel-menu`），sway 用规则定位。
4. **图标主题**：`adwaita-icon-theme` + `hicolor-icon-theme`，按 `.desktop`
   的 `Icon=` 名取真图标，取不到才退回字符底板。
5. **菜单定位用 absolute**：`move position` 相对工作区原点（有窗口后是
   16,16），菜单必须写 `move absolute position 410 232` 才能稳定落位。
6. **锁屏覆盖整块输出**：layer OVERLAY + `exclusive_zone=-1` + 键盘
   EXCLUSIVE；配合 sway `mode "shui-lock"` 屏蔽默认快捷键（V25）。
7. **空闲锁定**：`shui-idle` 直读 evdev 计时，锁进程异常消失时恢复
   `mode default` 并重新计时（V25）。

### 5.3 数据流

```
shuiosd ──unix socket──▶ shui-ctl ──▶ shui-panel 状态区
   │                                  shui-tray
   └─ MCP 总线 ──▶ 智能体（和人是同一套能力）

sway ──IPC(SWAYSOCK)──▶ shui-panel（窗口列表）/ shui-lock（mode 切换）/ Alt+Tab 脚本
evdev ──/dev/input/event*──▶ shui-idle ──spawn──▶ shui-lock（空闲锁定）

shui-pkg ──▶ /var/lib/shuios/pkg/share/applications ──▶ 桌面图标 / 开始菜单

shui-settings（AI 页）──shui-ctl ai──▶ shuiosd ──curl/HTTPS──▶ 远程提供商
                                      └──http://127.0.0.1:8080──▶ llama-server
```

## 8. 风险与对策

| 风险 | 对策 |
| --- | --- |
| 无 GPU，动画卡 | 只做 ≤120ms 淡入/位移；不做模糊/阴影 |
| 我无法看图 | `--dump-layout` + 像素统计 + 用户抽查 |
| adwaita 体积（~10MB） | 只装 16/24/48 三个尺寸 |

### 9.1 合并式任务栏怎么实现

数据源是 sway 的 IPC（unix socket `$SWAYSOCK`，JSON 事件）。
**不打算在 C 里手写 JSON 解析**——Rust 侧已经有 serde_json：

```
sway IPC ──订阅 window / workspace 事件──▶ shui-ctl windows --follow
                                            （常驻，每次变化打印一行 TSV）
                                                     │
                              GIOChannel 读管道 ◀────┘
                                                     │
                                            shui-panel 维护按钮列表
```

TSV 每行：`app_id \t title \t focused \t con_id \t workspace`

按钮状态机（V24 已实现前三行 + 右键）：

| 状态 | 外观 | 点击 |
| --- | --- | --- |
| 已安装未运行 | 图标，无指示线 | 启动 |
| 运行未聚焦 | 图标 + 14px 主色短线 | 聚焦（`swaymsg [con_id=…] focus`） |
| 运行且聚焦 | 图标 + 22px 主色线 | 最小化（移到 scratchpad） |
| 多窗口（2+） | 只有一个按钮，无分组/缩略图 | 聚焦最近一个（待做：分组菜单） |
| 悬停 | 底色变亮 + tooltip 显示窗口标题 | — |
| 右键 | — | **直接关闭**该应用（layer surface 不能弹 xdg_popup；上下文菜单待做） |

没有固定项的应用（比如以后装的浏览器）运行后自动追加按钮。

### 9.2 桌面图标层（依赖 layer-shell）

桌面图标必须在**所有应用窗口之下**。sway 里浮动窗口永远画在平铺窗口之上，
普通 GTK 窗口做不到"垫底"，所以它必须是 **layer-shell 的 background 层**：

```
zwlr_layer_shell_v1.get_layer_surface(..., layer=BACKGROUND, namespace="shui-desktop")
anchor = 左上；exclusive_zone = -1（不占位）
```

图标来源（按优先级）：

1. 固定 4 项：此电脑（`shui-ctl sys`）、工作区（`mc /workspace`）、软件商店、终端
2. `/usr/share/applications/*.desktop`（系统自带）
3. `/var/lib/shuios/pkg/share/applications/*.desktop`（`shui-pkg` 装的）

过滤：`NoDisplay=true` 不显示；`Terminal=true` 默认不显示（可配置）。

交互：单击选中、双击打开、右键菜单（打开 / 在终端里打开 / 卸载）。
