# 视觉规范（设计令牌 v4）

v4 的设计目标是 **Windows 形态**：深色底 + 扁平色块 + 底部 40px 任务栏，
没有顶栏、没有 Dock、没有玻璃/半透明。v3 的 macOS 毛玻璃路线已作废。

> 依据：用户原话「你就模仿 Windows 知道不」（见 `docs/07-界面规划.md`）。
> 深色扁平也是软渲染友好路线——任务栏与菜单都是不透明纯色，重绘成本恒定。

## 0. 唯一色源怎么落地

令牌以 **C 头文件**为唯一来源：`br2-ext/board/shuios/common/ui/shuios-ui.h`。

* `shui-panel`、`shui-settings`、`shui-files`、`shui-store` 的 `.mk` 都用 `-I`
  指向该目录，改一处、所有界面一起变。
* `foot`（ini）、`sway`（config）、`swaybg`（壁纸色）读静态配置，没法 include，
  只能照本表抄；**改动时以本文档与 ui.h 为准**。
* v4 全部颜色不透明，GTK CSS 直接写 `UI_HEX_*` 即可；v3 因半透明才需要的
  `rgba()` 双形态（`UI_CSS_*`）已随玻璃体系一起删除。

## 1. 颜色

| 角色 | token | 色值 | 用途 |
| --- | --- | --- | --- |
| 窗口 / 桌面 / 终端底 | `BG_WINDOW` | `#0A0C0F` | foot 等深底窗口 |
| 面板底 | `BG_PANEL` | `#12151A` | 任务栏、开始菜单 |
| 卡片底 | `BG_CARD` | `#181C22` | 卡片、输入框、图标底板、电源按钮 |
| 悬停底 | `BG_HOVER` | `#21262D` | 任务栏按钮 / 菜单格 hover |
| 描边 | `LINE` | `#292E36` | 所有 1px 边框、任务栏上沿 |
| 主文字 | `FG` | `#EEF1F4` | 正文、时钟（时:分） |
| 次文字 | `FG_DIM` | `#9AA4AE` | 摘要、状态栏、菜单格名字 |
| 弱文字 | `FG_WEAK` | `#6B747D` | 元信息、禁用、时钟日期 |
| 强调 | `ACCENT` | `#35A7CB` | 焦点框 / 主按钮 / 品牌「氵」/ 运行指示线 |
| 强调悬停 | `ACCENT_HI` | `#4FBEDA` | 主按钮 hover（只亮一档） |
| 强调文字 | `ACCENT_ON` | `#08161C` | accent 实心底上的文字 |
| 错误 | `DANGER` | `#E0574F` | 仅错误状态 |

**硬规则**

1. 深色底 + 扁平色块；**不做玻璃、半透明、tint**。任务栏和菜单一律 `BG_PANEL`。
2. `ACCENT` 克制使用：焦点框、主按钮、品牌「氵」、运行指示短线，除此之外不出现。
3. **同一语义只有一个色值**——不要在组件里再写一遍 hex / rgba。
4. 界面不假设阴影 / blur 存在；有无特效都由 `effects.conf` 档位决定（见 §6）。
5. 壁纸只作背景（明亮渐变：蓝 `#5B8DEF` → 紫 `#9B7BF0` → 粉 `#E08BC0`，
   `tools/make-wallpaper.py` 生成）；界面材质不依赖壁纸明暗。

## 4. 布局（Windows 单条）

* **没有顶栏**。工作区信息（智能体/内存/根文件系统）并进任务栏右侧状态区。
* **任务栏**：`shui-panel`，layer-shell surface。
  * namespace `shui-panel`，layer TOP，锚定 底/左/右，`exclusive_zone=40`，
    keyboard mode NONE。高 40（含上沿 1px `LINE`），`BG_PANEL`。
  * 左 → 右：开始按钮（44×40，主色「氵」20px）→ 固定+运行合并按钮
    （每格 44 宽，图标 24）→ 弹性空白 → 音量按钮（32×28，16px 主题图标
    `audio-volume-*`；左键静音、滚轮 ±5%、右键声音设置；tooltip 显示百分比，
    V26）→ 状态文本（11px `FG_DIM`，`shui-ctl bar --text`）→ 时钟
    （两行：`HH:MM` 12px 粗 `FG`，`MM-DD` 11px `FG_WEAK`）。
  * 运行指示：图标下方 3px 高 `ACCENT` 短线，运行 14px / 聚焦 22px；
    hover 底 `BG_HOVER`、6px 圆角（左右各留 4px）。
  * 因为带独占区，平铺/最大化窗口自动停在任务栏上沿，不会被盖住。
* **开始菜单**：独立 toplevel（layer surface 不能弹 xdg_popup），
  app_id `shui-panel-menu`，460×520，`BG_PANEL` + 1px `LINE` + 12px 圆角。
  * 头部：品牌 ⊙（22px，`ACCENT`）+「shuios」（13px 粗 `FG`）
  * 搜索框：`BG_CARD` 底、`LINE` 描边、8px 圆角、聚焦描边 `ACCENT`
  * 应用网格：48px 图标 + 名字（11px `FG_DIM`，最多两行）；hover `BG_HOVER`
  * 底部：锁屏 / 注销 / 重启 / 关机；锁屏用 `powerprimary`（`ACCENT` 底、
    `ACCENT_ON` 字），其余 `BG_CARD` 底、8px 圆角。
  * 位置：任务栏正上方居中，目标落点 **x=(1280−460)/2=410，
    y=800−40−8−520=232**，底边离任务栏 8px。sway 规则必须用
    `move absolute position 410 232`——`move position` 相对工作区原点，
    工作区有过窗口后原点变成 (16,16)，同一规则会差 16px（V24 实测）。
* **锁屏**：`shui-lock`，layer OVERLAY 全区（1280×800，`exclusive_zone=-1`），
  键盘独占。
  * 背景：壁纸按窗口缩放，再叠 `BG_WINDOW` 78% 暗化；不使用 blur。
  * 时钟 `56px` 粗 `FG`（`HH:MM`），日期 `13px` `FG_DIM`
    （`YYYY年M月D日 星期X`，不依赖 locale）。
  * 卡片：368px 宽、`BG_CARD` 底、1px `LINE`、12px 圆角，内边距 24。
    头像 56px 圆（`氵` 26px `ACCENT`）→ 用户名 15px 粗 `FG`（root）
    → 「shuios · 氵」11px `FG_WEAK` → 密码框 320×40（`BG_WINDOW` 底、
    `LINE` 描边、聚焦 `ACCENT`）→ 解锁按钮 320×40（`ACCENT` 底、
    `ACCENT_ON` 字、8px 圆角）→ 错误提示 11px `DANGER`（默认隐藏）。
  * 左下提示 11px `FG_WEAK`：「Win + L 锁定 · 空闲自动锁定」。
  * 右下：重启 / 关机两个 11px 按钮，`BG_CARD` 底、8px 圆角；点击变
    「再点一次」`DANGER` 描边，3 s 内二次点击才执行，超时恢复原样。
* **sway 浮动窗口落点**：其余规则仍用 `move position`，它相对工作区原点，
  在 outer gaps 8 + 1px 边下实际落点 = 写值 + (16,16)（V16 起的老约定）。
  改窗口规则时按「目标 − 16」写；菜单是唯一用 absolute 的例外。
* 默认窗口**浮动**而不是平铺：平铺会把屏幕铺满、壁纸完全看不见，观感像 IDE。
  * 软件商店 900×620，居右
  * 文件管理器 / 设置中心 900×620
  * 终端 556×380，居左
  * 需要平铺时 `Super+Shift+Space` 切回。

## 5. 图标与品牌

**优先用真图标主题**（`hicolor-icon-theme` + `adwaita-icon-theme` 已进镜像）：

* `.desktop` 里有 `Icon=` 的，按图标名解析成真图标（**先剥掉 `.svg/.png`
  扩展名**，图标主题按名字索引，带扩展名查不到，踩过）。
* 取不到图标时才退回自绘：`BG_CARD` 圆角底板 + 1px `LINE` 描边 +
  `FG_DIM` 字符。任务栏图标 24px，菜单网格 48px。

**品牌标记**：

* 任务栏开始按钮：水部首「氵」，20px `ACCENT`（`shui-panel.c: on_draw_start`）。
* 开始菜单头部：圆环 + 圆心点（⊙），22px `ACCENT`
  （`shui-panel.c: draw_dot_mark()`；环线宽 = 半径 × 0.30、点半径 = 半径 × 0.36，
  缩放到任何尺寸都不糊）。
* 开机/关机动画里用大字「氵」，只出现在 `shuios-splash`。

## 6. 特效档位（swayfx）

圆角 / 阴影 / blur 走 GLES2，开多少由 `shuios-session.sh` 按 GPU 驱动写到
`/run/shuios/compositor/effects.conf`，sway-config `include` 它：

| 档位 | 触发 | corner_radius | shadows | blur |
| --- | --- | --- | --- | --- |
| 满效 | 真实 GPU（i915/amdgpu 等） | 10 | enable | enable, 3 passes, radius 5 |
| 轻效 | 软件渲染（QEMU virtio-gpu 无 virgl、bochs） | 6 | disable | **disable** |

v4 的界面本身**不透明**，blur 开不开都不影响任务栏/菜单观感（只影响窗口
边角后的背景）。轻效档关 blur 仍是硬规则（V16：llvmpipe 下 blur 背景纹理
逐帧不稳定，半透明面会跳色，而且整条脏区重绘）。

## 7. 为什么这么定

* 用户明确要 Windows 形态：底部任务栏、开始按钮在左、时钟在右。v3 的
  macOS Dock + 顶栏是上一轮的方向，已整体退役（V24 删除 waybar）。
* 深色扁平在虚拟机上代价最低：没有半透明合成、没有大面积 blur，任务栏
  只有状态文本和时钟在变，静置接近零重绘（V24 像素验收：底部 40 行
  `#12151A` 占 92.59%，ACCENT 仅 0.04%）。
* 令牌集中到 `shuios-ui.h` 后，换配色只改一个文件；`UI_STR()` 让 CSS 里的
  字号/圆角也吃宏，不必再手抄数字。
